## Project Name
**Evident**

## Elevator Pitch
Code-Grounded Career Intelligence Engine — Don't Claim It. Prove It.

## Description
**The Problem: Absence of Evidence, Not Absence of Work**
Students and early career builders rarely have an absence-of-work problem. They have GitHub repositories, hackathons, college capstones, pull requests, and late-night prototypes. But all of that work is scattered across branches and files. When applying for internships, they either generate generic, hallucinated buzzwords with AI (*"Architected scalable cloud microservices"*) or undersell what they actually built.

**The Solution: Evident**
Evident replaces AI hallucination with verifiable technical provenance. It models technical evidence across 5 orthogonal dimensions (Direct Source, Supported, Partial, Evidence Gap, User-Declared) to establish absolute truth about a candidate's capabilities.

**How it works (The 3-Step Magic Loop):**
1. **Living Evidence & Interactive Graph Explorer:** Automatically normalizes connected repositories and extracts verifiable skills, files, and commits into an Interactive Evidence Graph.
2. **Transparent Opportunity Matching:** Paste any job description to produce an honest Evidence Coverage Matrix (`5 Direct`, `2 Supported`, `1 Gap`) rather than arbitrary fake percentages.
3. **Application Studio & The "Why This Bullet?" Inspector:** Synthesizes grounded resume bullets linked directly to retrieved evidence IDs. Tapping `[Why this claim?]` reveals the exact file path and matching commit SHA. It even features an Architectural Defense Arena that generates technical interview questions derived directly from your own code!

**RevenueCat Integration & Monetization**
Evident is monetized via a **Living Career Memory Entitlement** (`proof_pro`), powered natively by RevenueCat (`react-native-purchases`). 
Pro transforms Evident from a one-time resume tool into a Living Career Memory that continuously monitors repositories and keeps evidence profiles up to date as you push code.
- **Annual Career Pass:** $49.99/year
- **Monthly Career Sprint:** $7.99/month (flexible for active recruiting cycles)
We utilized RevenueCat's Test Store environment to successfully implement and verify the entire purchase lifecycle, entitlement listeners, and restore functionality without needing live App Store credentials.
